# Stargaze

A cozy little spaceship cabin drifting through a procedurally generated galaxy. Lean back, look out of the
window, fly to a ringed planet, and let the radio play lofi.

Work in progress.

- The cabin is built and lit in Blender (baked lighting), then shown in the browser with three.js.
- The galaxy, star systems, planets, asteroid fields and sky are generated live from a seed.
- The ship's radio plays generative lofi (every star system has its own stations), or your own music.

## Run it locally

```sh
npm install
npm run dev
```

Then open the address Vite prints.
